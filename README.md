# cashflow

家計のキャッシュフロー（残高予測）Webアプリ。スマホ（Android）とパソコンの両方から使う。

- アプリ：https://sasakamangt.github.io/cashflow/
- データ：非公開リポジトリ sasakamanGT/cashflow-data の data.json（GitHub API で読み書き）
- アクセストークン：fine-grained「cashflow-app」（cashflow-data の Contents 読み書きのみ）。各端末のアプリの設定画面で入力し、端末内（localStorage）だけに保存
- **プログラムに実際の金額やトークンは書かない**
- 次に作業するAIへの引き継ぎメモ（決めたことの理由・頼み方のルール・注意点）：[HANDOFF.md](HANDOFF.md)

## データ構造（data.json）

- balances: [{date, bank, sec}] 実際の残高の記録
- items: [{id, type:in|out|transfer, account:bank|sec, to, date, name, amount, repeat:none|monthly|yearly, until, shift:false|true|'prev'}]
  - shift：true＝土日祝・年末年始なら翌営業日、'prev'＝前営業日
- marks: {"itemId|予定日": {status:done|skip|moved, date, amount, type, account, to, name}} 実績確認の記録

## 仕様

### 口座
- 銀行、証券口座の現金の2つ。予定ごとに口座を選ぶ（例：iDeCoは証券口座から毎月）
- 種類：入金／出金／振替（口座間）

### 予定
- 日付・項目・金額・口座・繰り返し（なし／毎月／毎年、終了日）
- 土日祝・年末年始（12/31〜1/3）のとき：そのまま／前営業日／翌営業日（祝日は計算で判定）
- 過去の予定もすべて保存

### 実績確認
- 予定日が来ても口座には反映しない。「実績確認」で確定したときに反映
- 予定日を過ぎた未確認の予定は「確認待ち」として上部に表示し、予測では今日に計上
- 実績確認：実際の日付・金額で確定／今回はなし（スキップ）／延期／予定を編集
- 予定日より前に確定しても、実際の日付は予定日のまま（その日になるまで残高に反映しない）
- メイン画面の明細には、日付が過ぎた実績は出さない（今日の分までは出す）。過去の実績は「一覧」で見られる
- 繰り返しは、その回だけ確定。確定した実績は一覧から修正・取り消しできる
- 一覧では、確定・スキップ済みの単発の予定は予定の欄に出さない（確定したものは「確定した実績」の欄に出る）
- 確定・スキップした回は、あとで予定の日付を変えても同じ月（毎年なら同じ年）に二重に出さない
- 今日以前の単発の予定を追加するときは「もう発生済み（実績として確定）」を選べる
- 現在の残高＝最後の残高記録＋その後に確定した実績（同じ日付なら入力した時刻で前後を判断。残高を記録したあとに入れた実績は計算に入る）
- 残高を記録すると、アプリ上の実績残高との差額を表示。記録日までに確認待ちがあれば警告
- 最初の残高記録日より前の予定は対象外

### 予測
- 繰り返しの予定を30年先まで展開して、日ごとの残高を計算
- 目的は「銀行がいつマイナスになるか」を知ること。自動補填はしない（証券から移すときは「振替」を登録）
- 月末残高の下に「○/○に銀行がマイナスになります。（銀行：−○○円）」と表示。金額はその月でいちばん少なくなるときの銀行残高
- 合計のグラフには、2口座の合計が0円を下回る日に赤い縦線

### 表示
- 色：10万円以上＝通常、1〜99,999円＝黄色、0円以下＝赤
- 月末残高（3か月分）、明細ごとの残高、「実績」「予定」のタグ
- メイン画面の並び：現在の残高 → 月末残高（3か月、銀行を大きく・合計を小さく）→ 確認待ち → 明細（今月と来月、「もう3か月表示」で追加）→ グラフ
- グラフ：「合計（2口座）の年末残高」の棒グラフだけ。0円になる時期を大きく表示し、金額は棒に最初から書く（タップしても変わらない）
- 追加画面：金額の下の［✓ 実績］（最初はこちら）／［予定］で、確定済みの記録か予定かを選ぶ。予定は0円も可

### 入力
- PC：直接入力（「2万3千」「1万+5000」のような式も可）＋金額欄の横の「テンキー」ボタン
- スマホ：画面テンキー（0・00・000・万・千・＋・−・⌫・C）

## 直し方（無料版など）
- 直したいファイルだけを差し替える。GitHubの「Add file」→「Upload files」にドラッグして「Commit changes」
- 見た目なら style.css、グラフなら chart.js、入力画面なら forms.js、計算なら calc.js

## トークンの更新（期限：2027年11月13日）
期限が切れると、アプリでデータを読み書きできなくなる（アプリの画面は開ける）。期限の前に作り直す。
1. GitHubにログインして https://github.com/settings/personal-access-tokens を開く
2. 「cashflow-app」を押す → 「Regenerate token」（トークンを再生成）を押す
3. Expiration（期限）で「Custom」を選び、1年後の日付を入れて「Regenerate token」を押す
4. 表示された github_pat_ で始まる文字列をコピーして、パスワード管理アプリなどに保存（この画面を離れると二度と表示されない）
5. 各端末でアプリを開き、⚙（設定）の「アクセストークン」に貼り付けて「保存」
- 権限（cashflow-data の Contents 読み書きのみ）はそのまま引き継がれる
- トークンはチャットに貼らない。アプリの設定画面に直接貼る

## 新しい端末で使い始める
1. ブラウザ（AndroidならChrome）で https://sasakamangt.github.io/cashflow/ を開く
2. 設定画面が出たら、保存しておいたトークンを貼り付けて「保存」
3. スマホは、右上の「⋮」→「ホーム画面に追加」でアイコンから起動できる
- データはGitHubにあるので、端末を変えても同じ内容が出る
- 古い端末を手放すときは、⚙ の「この端末からトークンを消す」を押しておく
